# BWL für Designer

Statische Lernapp zur Klausurvorbereitung. Die Fragen wurden mithilfe von KI aus
Vorlesungsfolien erstellt und anschließend gegengeprüft.

## Lokal bauen

```bash
python3 build.py
```

Der Build erzeugt `index.html` für GitHub Pages und `BWL-Trainer.html` für die
lokale Nutzung.

## Datenschutz

Die App hat kein eigenes Backend. Lernfortschritt und Einstellungen werden nur
im lokalen Browserspeicher des jeweiligen Geräts gespeichert.
